# 7. Planificación del proyecto

Este documento corresponde a la planificación y el diseño. No se están instalando ni configurando sistemas en esta práctica.

## 7.2. Metodología Scrum
Scrum es un marco de trabajo ágil que organiza el trabajo en periodos cortos llamados *sprints*. El equipo selecciona tareas, las realiza, revisa el resultado y adapta la planificación según el avance.

- **Product Owner:** prioriza necesidades y comprueba que el resultado responde a lo solicitado.
- **Scrum Master:** ayuda a organizar el trabajo y eliminar bloqueos.
- **Developers / equipo de desarrollo:** realizan análisis, diseño, documentación y pruebas.

En este proyecto académico los integrantes pueden repartirse estas responsabilidades. Son funciones de trabajo, no puestos nuevos de la empresa ficticia.

## 7.4. Evidencias de Trello
**Enlace al tablero:** pendiente de añadir cuando se cree y se comparta con el profesorado.

**Captura de pantalla:** pendiente de añadir una captura real que muestre listas, tarjetas y responsables. No se incluye una captura inventada.

## 7.5. Seguimiento
Al inicio de cada sprint se seleccionan tareas prioritarias. Durante el trabajo se actualiza la lista de cada tarjeta y se anotan bloqueos. Al finalizar se revisa que los documentos estén completos, que las fuentes sean consultables y que las decisiones coincidan con el presupuesto.

La entrega estará preparada cuando estén terminados los siete documentos, el diagrama se visualice correctamente, el tablero sea accesible para el profesorado y el repositorio incluya el commit final.
